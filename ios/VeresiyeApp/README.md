# Veresiye iOS uygulaması

Bu Xcode projesi Web uygulamasını native iOS uygulaması olarak açar.

## Mac'te çalıştırma

1. Xcode'u açın.
2. `VeresiyeApp.xcodeproj` dosyasını açın.
3. Sol üstten iPhone veya bağlı iPhone'u seçin.
4. Signing & Capabilities bölümünde Team olarak Apple ID'nizi seçin.
5. Run tuşuna basın.

Ücretsiz Apple hesabıyla uygulama telefonunuza yüklenir; Xcode tarafından verilir. Ücretsiz hesabın imzaları yaklaşık 7 gün sonra yenilenmelidir.

## Önemli

Windows'ta Apple imzası ve `.ipa` yüklemesi yapılamaz. Apple'a gerçek `.ipa` imzası yalnızca Mac/Xcode veya ücretli Apple Developer hesabı ve CI secrets ile yapılabilir.
